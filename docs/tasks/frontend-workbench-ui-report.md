# بهبودهای پوستهٔ فرانت‌اند — گزارش

**تاریخ:** ۲۰۲۶-۱۰-۲۶ · **بک‌اند:** بدون تغییر

- `ActiveWindowsBar` زیر سربرگ، مقصدهای باز را با رنگ ماژول، کارت‌های wrapشونده، بستن و بازکردن route نمایش می‌دهد؛ اسکرول افقی ندارد. وضعیت مقصدها در حافظهٔ همان پوسته است.
- برای فرم‌های مسیر `/new` و `/edit` دکمهٔ بازگشت به تاریخچه یا fallback والد اضافه شد.
- Tooltip نوار جمع‌شده به سمت چپ آیکون می‌رود؛ ناحیهٔ Toast به سمت انتهایی viewport و لایهٔ بالاتر از سایدبار منتقل شده و انیمیشن rise موجود سبک باقی مانده است.
- دسته‌بندی منوی حسابداری به کدینگ، اسناد، گزارش‌ها و تنظیمات تفکیک شد؛ مسیر hub برای breadcrumb حفظ شده است.

## محدودیت شناخته‌شده

نوار پنجره‌ها route را دنبال می‌کند، اما صفحات را mounted نگه نمی‌دارد و state فرم را هنگام جابه‌جایی تضمین نمی‌کند. برای فرم‌های تغییرکرده همچنان باید ذخیره کرد یا بعداً سیاست draft/dirty-guard مشترک اضافه شود.

## تست

تست‌های رفتاری مستقل برای نوار پنجره‌ها، بازگشت فرم و جای Toast اضافه شدند. تست‌های منوی حسابداری و breadcrumb نیز مطابق دسته‌بندی جدید به‌روز شدند.
