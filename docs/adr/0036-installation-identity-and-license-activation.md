# Moved: ADR-0036 (installation identity) → ADR-0045

This path used to hold *Persistent installation identity and local license
activation*. Two records shared the number 0036: this licensing record and
[ADR-0036 — legal reporting architecture](./0036-legal-reporting-architecture.md)
(the registered one). PDR-11 §19 recorded the collision as **CF-14**.

On 2026-10-11 the licensing record was renumbered to
**[ADR-0045](./0045-installation-identity-and-license-activation.md)** (next
free identifier; ADR-0027 stays unused). Its decision text is unchanged, and
this pointer file exists only so historical links do not break. It is not an
ADR and is deliberately absent from the ADR index.
